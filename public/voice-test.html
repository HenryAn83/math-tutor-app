🗣 선생님 목소리 들어 보기

이 폰에 들어 있는 목소리로 같은 예문을 읽어요. 위에 있을수록 앱이 더 좋다고 보고 고르는 목소리예요.

목소리를 더 좋게 하려면 (폰 설정)

아이폰: 설정 → 손쉬운 사용 → 읽기 및 말하기 → 음성 → 한국어 → 유나(프리미엄) 또는 (향상됨) 내려받기. 영어는 English → Ava(프리미엄) 등. 받은 뒤 이 페이지를 새로 고침하면 맨 위에 나와요.

안드로이드: 설정 → 일반 → 텍스트 음성 변환(TTS) → 기본 엔진 Google 또는 삼성 → 음성 데이터 설치에서 한국어 고품질 받기.

컴퓨터: 마이크로소프트 엣지로 열면 "Natural" 목소리가 나와요(가장 자연스러움).
